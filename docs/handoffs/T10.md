## Files

| File | Why |

`session.ts` provides:
- **`startSession(rules, sessionId, generator)`** builds an empty board, deals a full tray (instance ids 1..n) and runs an immediate legal-move check.
- **`placePiece(rules, state, command)`** runs the GDD 5.1 order:
  1. Guards, in order: session → game over → revision → live instance → `canPlace`.
  2. Place, then detect and clear all lines at once.
  3. Add the score, using `addScore`'s overflow guard.
  4. Consume the slot. Refill only if every slot is empty, with fresh instance ids.
  5. Check for any legal move, then increment the revision once.

  It returns a frozen `MoveResult` containing the new state, or `{accepted: false, reason}` with no effects.
- **`GameSession`** holds the one authoritative state and replaces it only on acceptance.

## Checks

`npx vitest run` passes 165 tests, 18 of them session tests (`docs/evidence/t10/session-tests.txt`):
- **Start:** empty board, tray of 3, revision 0, frozen.
- **Commit:** `square_3` scores 9. Only the selected slot becomes null, other slots keep identity and position, the revision becomes 1, and the generator isn't touched without a refill.
- **Refill:** happens exactly once, after the third consumption (dealt 0/0/3), with instance ids 4–6 and generator state advanced by exactly 3.
- **Clearing:** the crossing fixture clears 19 cells and scores 21, and occupancy after = before + placed − cleared.
- **Blocked fresh tray:** a refill of three `square_3` on a checkerboard ends the run immediately. Further commands return `game_over`.
- **One blocked slot:** an unfittable `square_3` alongside a fitting `single` keeps the run active.
- **Rejections:** `stale_session`, `stale_revision`, consumed and never-dealt `unknown_slot`, and `illegal_placement` (overlap, outside, negative, fractional). Each one leaves the identical state object with the same state hash.
- **Duplicates:** a repeated command is rejected (`stale_revision`), and re-sending it at the new revision is also rejected (`unknown_slot`), so the score stays 1.
- **Old sessions:** a delayed command from an old session whose instance id collides with the new session's gets `stale_session`.
- **Generator safety:** 50 rejected commands leave the weighted generator object unchanged.
- **Determinism:** a greedy run with seed 12345 played twice gives identical per-move state-hash traces. It lasts 26 moves, scores 147, and ends with final hash `4dfd89d8568889e9`.
