## Decisions

- New game from the menu also asks when the stored (not just the in-memory) run is unfinished, since starting would replace it.
- With `?seed=`, only the first run uses the fixed seed; Play again deals fresh pieces.
- Continue after Main menu re-reads storage (after this tab's writes finish) rather than reusing memory, so it shows exactly the last completed save. While saving is off, it uses the in-memory run.
