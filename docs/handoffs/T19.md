## Decisions

- Native `<dialog>` instead of custom overlays for information screens. In Chromium, Tab past the last control goes to the browser UI, with the page behind inert. The test asserts focus never reaches the page.
- Settings live in the save envelope (no separate store), so they share its ordering, conflict and session-only rules.
- The 15 s load timeout covers content fetching; renderer startup already fails fast.
