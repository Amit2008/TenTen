| File | What |
|---|---|
| `index.html` | A "Graphics paused" overlay (`#graphics-lost`, an alertdialog). It comes last in the game group so it covers every other screen |
| `src/bootstrap/main.ts` | Context-loss handling (GDD 8.2), listed below |

| `docs/evidence/t25/` | The fault matrix, the injection script and its raw output |

On context loss, `main.ts` pauses the run, cancels any drag and stops all frames. It shows the overlay and makes the canvas, slots, pause and sound buttons, and every other screen inert. The command path also refuses moves while the context is lost. If the context is not restored within 10 s, the overlay offers Reload and shows the current save status.

On restore, `main.ts` draws the committed state once with Pixi's rebuilt resources. A run then stays paused until Resume, while the menu, results and conflict screens keep drawing. Nothing is replayed.

Pixi 8.22 already calls `preventDefault` on loss and rebuilds GPU resources on restore (`GlContextSystem`), so `src/adapters/rendering` needed no change.
