## Checks

`npx vitest run` passes 139 tests (`docs/evidence/t08/generator-tests.txt`):
- **Golden vectors:** state 1 gives **270369, 67634689, 2647435461**, as specified.
- **Recorded sequence:** seed 12345 makes 24 draws over weight 19, ending in state 1652327021. An independent Python implementation produced the same sequence.
- **Rejection boundaries:** bound 2 rejects only the top value. Bound 19 rejects exactly 5 outputs. Bound 3 rejects nothing. The weight cap 2147483647 is handled.
- **Weighting:** weights 1/2/3 over 60k draws land within 5% of the expected 10k/20k/30k. In the classic catalog all 19 shapes appear, and trays can contain duplicates.
- **Restore and replay:** restoring after 17 draws through JSON gives the same next 23 deals as an uninterrupted run.
- **Purity and validation:** a frozen generator is never mutated, and seeds normalize correctly. Corrupt saved state is rejected (0, 2^32, fractional, negative seed, wrong algorithm, wrong version, extra key).
