## Files

| File | Why |
|---|---|
| `src/adapters/rendering/webgl-app.ts` | `createWebGL2App()` uses Pixi with `preference: ['webgl']`, so Pixi tries no other backend. It then requires `RendererType.WEBGL` and `webGLVersion === 2`, and throws `RendererUnavailableError` otherwise. `fitToHost()` contain-fits the 720×960 logical area using a ResizeObserver, a DPR-change listener, `resolution = min(DPR, 2)`, and a CSS size kept separate from the backing size |
| `src/bootstrap/main.ts` | Loading, ready and error flow. A load-generation guard means a stale startup can't overwrite a retry. Teardown disconnects the observers and destroys the app |
| `src/bootstrap/app-url.ts` | `appUrl()` resolves runtime URLs against `import.meta.env.BASE_URL`, never the origin root |
| `src/bootstrap/shell.css` | Letterboxed layout, safe-area padding, `touch-action: none` on the canvas only, 44px Retry button, focus rings |
| `index.html` | Semantic status line, plus an HTML error panel (`role="alert"`) with a Retry button and help link that needs no canvas |
| `public/icon.svg` | Original app icon placeholder (favicon). The shell loads it through Pixi `Assets` to prove base-aware loading |
| `playwright.config.ts` | Builds and previews the app twice, at `/` (port 4173) and `/TenTen/` (port 4174), and runs every spec against both |
| `tests/browser/shell.spec.ts`, `unsupported.spec.ts`, `tests/unit/app-url.test.ts` | Acceptance tests |

What the browser tests prove:
- **WebGL2:** the canvas context is a `WebGL2RenderingContext`. GPU: SwiftShader, because the runs are headless.
- **Base paths:** `icon.svg` is fetched from `${base}icon.svg` and returns 200 at both bases.
- **DPR:** at DPR 1, 2 and 3 the backing buffer equals CSS size × min(DPR, 2), and the aspect ratio stays 3:4.
- **Resizing:** going from 1280×720 to 360×640 refits the canvas with no cropping.
- **No WebGL:** Chromium launched with `--disable-webgl --disable-webgl2 --disable-3d-apis` shows the HTML error. No canvas exists, Retry is focused, and Retry fails again cleanly.

The screenshots are `docs/evidence/t03/shell-{root,nested}.png` and `unsupported-{root,nested}.png`.
